Route to **cs-cto-advisor** — Technical Advisory workflow.

1. Ask the user to describe: the technical challenge or decision, current stack, team size, and constraints (if not in $ARGUMENTS).
2. Read the CTO advisor skill:
   ```bash
   cat c-level-advisor/cto-advisor/SKILL.md
   ```
3. Analyse across four dimensions:
   - **Architecture:** Design trade-offs, scalability, maintainability
   - **Team:** Skill gaps, hiring needs, productivity impact
   - **Risk:** Technical debt, security, operational risk
   - **Cost:** Build vs buy economics, infrastructure spend
4. Produce a technical decision document:
   - Options matrix (2-3 options with pros/cons)
   - Recommended approach with rationale
   - Implementation roadmap (phases)
   - Success metrics and rollback plan
5. Deliver: Technical brief with clear recommendation and implementation plan.
