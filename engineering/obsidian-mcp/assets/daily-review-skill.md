# Daily Review Skill

> Fertige Skill-Datei — direkt in deinen Vault unter `Skills/daily-review.md` kopieren.

---

## When to use

End of day, or when user says "review my day", "daily review", or "Tagesrückblick"

---

## Inputs

- Today's Daily Note (`Notes & Knowledge/Daily Notes/YYYY-MM-DD.md`)
- Today's calendar events (optional — via Google Calendar MCP)
- Open tasks from `Tasks & Next Actions/`

---

## Steps

1. Read today's Daily Note and any notes created today
2. Read open tasks (look for `- [ ]` items across the vault)
3. Summarise key events and what was accomplished
4. List 3 wins (things that went well)
5. Identify 1 challenge or blocker
6. Suggest 3 priorities for tomorrow
7. Append the review to today's Daily Note under `## Daily Review`

---

## Example

```
"Review my day"
"Mach meinen Tagesrückblick"
"daily review"
```

---

## Save to

Append to `Notes & Knowledge/Daily Notes/{{today}}.md` under `## Daily Review`
