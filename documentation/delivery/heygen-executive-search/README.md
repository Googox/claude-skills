---

## Produktionsschritte

1. HeyGen öffnen → eigenen Avatar auswählen
2. Skript aus der jeweiligen Briefing-Datei kopieren (ohne Regie-Anweisungen)
3. Pausen mit HeyGen-Pause-Markup einfügen (Komma/Punkt oder manuelle `<break>` Tags)
4. Hintergrund, Untertitel und Sprechtempo laut Briefing einstellen
5. Vorschau prüfen: Lipsync, Pausen, Betonungen
6. Export gemäß Checkliste in der jeweiligen Datei
