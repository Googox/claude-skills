# HeyGen Video Briefing — LinkedIn (60 Sekunden)

**Thema:** Warum braucht eine Führungskraft die Betreuung durch einen Executive Search?
**Plattform:** LinkedIn
**Zieldauer:** 60 Sekunden

---

## Technische Einstellungen

| Einstellung | Wert |
|---|---|
| **Avatar** | Eigener HeyGen-Avatar |
| **Format** | 16:9 — 1920×1080 px |
| **Sprache** | Deutsch (Deutschland) |
| **Sprechtempo** | 0.85× |
| **Hintergrund** | Modernes Büro, Bücherregal oder neutrales Dunkelblau |
| **Untertitel** | Aktiviert — Arial/Inter, Weiß, mittig unten |
| **Musik** | Keine (LinkedIn-Autoplay läuft stumm) |
| **Export** | MP4 H.264, max. 200 MB |

---

## Skript mit Regie-Anweisungen

```
[PAUSE 0.5s — Blickkontakt zur Kamera]

„Die meisten Führungspositionen werden nie ausgeschrieben."

[PAUSE 1.0s — Aussage wirken lassen]

„Trotzdem werden sie besetzt — von jemandem."

[PAUSE 0.5s]

„Die Frage ist: Von wem?"

[PAUSE 1.5s — längste Pause, maximale Wirkung]

„Topunternehmen vertrauen nicht auf Jobportale.
Sie vertrauen auf Netzwerke. Auf Empfehlungen.
Auf diskrete Suche."

[PAUSE 0.8s]

„Als Executive Search Partner begleite ich Führungskräfte
genau dort —
[PAUSE 0.3s]
wo der sichtbare Markt aufhört und der echte anfängt."

[PAUSE 0.8s]

„Wir klären gemeinsam:
Welche Positionen passen wirklich zu Ihnen?
Welche Unternehmen suchen jemanden wie Sie —
ohne es zu zeigen?
Und wie positionieren Sie sich so,
dass die richtigen Menschen auf Sie zukommen?"

[PAUSE 0.8s]

„Vertraulich.
[PAUSE 0.3s]
Strategisch.
[PAUSE 0.3s]
Auf Augenhöhe."

[PAUSE 1.0s]

„Wenn Sie bereit sind für den nächsten Schritt —
schreiben Sie mir einfach eine Nachricht."

[PAUSE 0.5s — Lächeln, Blick bleibt in Kamera]
```

---

## Betonungsguide

| Wort / Phrase | Anweisung |
|---|---|
| „nie ausgeschrieben" | Langsamer sprechen, deutlich |
| „Von wem?" | Kurze Pause davor + danach |
| „diskrete Suche" | Leise betont |
| „Vertraulich. Strategisch. Auf Augenhöhe." | Jedes Wort einzeln, Mikropause dazwischen |
| „einfach eine Nachricht" | Freundlich, einladend |

---

## Untertitel-Regeln

- Max. **5–6 Wörter** pro Einblendung
- Satzzeichen-Pausen = Untertitel-Wechsel
- „Von wem?" als eigene Einblendung (allein stehend, große Wirkung)

---

## Call-to-Action (Einblendung am Ende)

**Text:** „Jetzt vernetzen" oder „Nachricht senden"
**Position:** Unten mittig, letzte 3 Sekunden
**Stil:** Weißer Button auf dunklem Hintergrund
